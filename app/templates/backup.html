What is in a backup, and how to use one

Each file is an ordinary zip. Inside:

  • finance.db — every job, quote, invoice, approval, check request and receipt.
  • documents/ — every PDF and photograph as it arrived.

To restore, stop the app and run:

python scripts/restore_backup.py latest

It checks the backup is sound before it touches anything, and moves whatever it replaces aside rather than deleting it. This has been rehearsed end to end — data destroyed, restored, app started, documents served — so it is a procedure rather than a hope.

Keep at least one downloaded copy somewhere that is not this server. That is the copy that survives losing the host.
