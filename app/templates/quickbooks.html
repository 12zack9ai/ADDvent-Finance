Nothing will happen until this is set up

QuickBooks Desktop has no cloud API — none. It cannot be reached over the internet, by us or by anybody else. The only supported way in is the QuickBooks Web Connector: a small Intuit program that runs on a Windows machine beside the company file and calls this site on a schedule. Everything below is already built and waiting for it.

  1. Set QBWC_PASSWORD and QUICKBOOKS_ENABLED=true.
  2. Download the .qwc file and open it on the Windows machine that can see the company file.
  3. An administrator approves the connection once, inside QuickBooks.

The full instructions, for whoever runs that machine, are in docs/QUICKBOOKS-SETUP.md.
